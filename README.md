# Coder Media Generation Skill

Codex skill for image generation/editing and text-, image-, or reference-driven video generation through the configured gateway.

Video model groups are read from the public pricing catalog. Each exact video group uses its own local API key; the image-generation key is separate. Keys are never stored in this repository.

Install this repository as the `coder-media-generation` Codex skill. Start with [SKILL.md](SKILL.md); model capabilities and API behavior are documented under [`references/`](references/).
